# app-privacy

Privacy policies for HARDWARIO's mobile apps, served by GitHub Pages:

- https://hardwario.github.io/app-privacy/proximos/ — ProXimos App (`com.hardwario.proximosapp`)
- https://hardwario.github.io/app-privacy/proximos/delete-account/ — its account-deletion page (Play Data safety "delete account" link)

Temporary home until the pages are live on hardwario.com
(`/legal/proximos-app-privacy/`). After the
move, replace each page with a redirect to its hardwario.com URL rather than
deleting it: Google Play checks that the old URL keeps resolving until the new
one is approved.

The editable source is the Claude doc each page was exported from; keep the two
in step.
